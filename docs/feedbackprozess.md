# Feedbackprozess

## Ablauf für Code-Reviews

1. Der Entwickler erstellt oder bearbeitet seinen Code.
2. Danach wird der Code zur Überprüfung bereitgestellt.
3. Eine andere Person kontrolliert den Code auf Fehler.
4. Verbesserungsvorschläge werden als Feedback mitgeteilt.
5. Der Entwickler setzt die Verbesserungen um.
6. Nach erfolgreicher Kontrolle wird die Aufgabe abgeschlossen.

## Ziel

Durch Code-Reviews sollen Fehler früh erkannt und die Qualität des Codes verbessert werden.
