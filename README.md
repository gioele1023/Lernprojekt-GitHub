# Lernprojekt-GitHub

## Ziel des Projekts
Dieses Repository wurde erstellt, um den Umgang mit GitHub zu üben. Dabei lerne ich, wie man Projekte organisiert, Issues erstellt und den Fortschritt mit einem Kanban-Board überwacht.

## Projektstruktur
- `src/`: Enthält die HTML-Datei des Projekts.
- `docs/`: Enthält zusätzliche Projektinformationen.
- `README.md`: Beschreibt das Projekt und enthält wichtige Informationen.

## Verwendete Tools
- GitHub
- GitHub Projects
- GitHub Issues
